== GATE-13.1-02 mapped onto task 13.2's sixteen isolation surfaces ==

13.1 section 2.2 found that test modules patch
`apps.applications.document_views.AccessScopeService`, a symbol task 9.4
removed, so `mock.patch` raises AttributeError **at fixture setup** and every
case in those files errors instead of running. The dispatch for 13.2 asks the
question this file answers: does any of them cover a surface in the isolation
matrix, in which case the browser row may be that surface's only live coverage.
