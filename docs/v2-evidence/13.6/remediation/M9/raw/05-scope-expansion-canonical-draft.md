The inherited M9 scope was expanded only where the whole-tree and required F3
journey exposed one shared safety defect: student answer writes were not one
versioned command. The expansion covers the canonical draft PATCH contract,
idempotency response serialization, the wizard's version/key propagation,
fail-closed resume hydration, and the F1-F3 adversarial harness rows.

This does **not** claim task 6.3 complete. `useAutoSave`, smart autosave, wizard
persistence, session/cache and offline recovery still cooperate as multiple
owners. It also does not authorize production deployment or sign-off.
