=== why html-report/ is not published, and what to use instead ===
Wed Aug 12 02:49:06 PM UTC 2026

Playwright's HTML reporter copies every trace and screenshot into
html-report/data/ verbatim, so the report was a byte-for-byte duplicate of
raw/artifacts/ at 116 MB on top of the artifacts' own 114 MB. Verified before
deleting: html-report/data held 112 files, and a sampled trace zip
  065d12990a9e829914272d25f157537a0875c328.zip
  sha256 7bccee2f3aa184500c35b0fc758d1202c941432e33766a0ec18334a81cd2141e
matched exactly one trace.zip under raw/artifacts/ — i.e. the same bytes.

What a reviewer uses instead (no report needed):
  npx playwright show-trace docs/v2-evidence/13.3/raw/artifacts/<test-dir>/trace.zip

Each trace embeds the screencast filmstrip, the DOM snapshot, the console and
every network call per step — which is what carries R18.2's browser-artifact
requirement on a box with no ffmpeg (13.2 section 7).

Kept: 54 traces + 54 per-test screenshots in raw/artifacts/, and the 149
reviewed screenshots in screenshots/, organised per viewport.

Regenerate the HTML report at any time from the JSON report:
  cd apps/admissions && bunx playwright merge-reports --reporter=html \
    ../../docs/v2-evidence/13.3/raw   # or re-run with the 13.3 config
