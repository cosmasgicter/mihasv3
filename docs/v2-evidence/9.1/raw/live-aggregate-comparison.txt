Task 9.1 — the roster's aggregates equal an independent SQL count (live system)
================================================================================

The pytest half of this claim is
`backend/tests/unit/test_application_query_contract_9_1.py::TestAggregatesEqualIndependentSql`
(15 counters recomputed with hand-written SQL against the same filtered set).
This file repeats the comparison against the **running** harness stack — a real
uvicorn backend answering a real cookie-authenticated HTTP request, and psql
inside the harness Postgres container — so the claim does not rest only on the
test client.

Captured: 2026-08-07 (UTC), immediately after the recorded browser run
(`harness-roster-journeys.txt`), which left 56 applications in the harness DB
(2 x 28: each Playwright project seeded its own two offerings).

reported 5.

--------------------------------------------------------------------------------
2. The same numbers, counted independently in psql
--------------------------------------------------------------------------------
$ docker compose -f harness/docker-compose.harness.yml exec postgres \
    psql -U "$POSTGRES_USER" -d "$POSTGRES_DB"

SELECT count(*)                                    AS total,
       count(*) FILTER (WHERE status = 'draft')     AS draft_count,
       count(*) FILTER (WHERE status IN ('submitted','under_review'))
                                                    AS decision_queue_count,
       count(*) FILTER (WHERE status IN ('approved','conditionally_approved','enrolled'))
                                                    AS accepted_count,
       count(*) FILTER (WHERE payment_status IS NULL
                           OR payment_status IN ('','not_paid','unpaid'))
                                                    AS payment_unpaid_count,
       count(*) FILTER (WHERE assigned_reviewer_id IS NULL)
                                                    AS unassigned_count
FROM applications;

 total | draft_count | decision_queue_count | accepted_count | payment_unpaid_count | unassigned_count
-------+-------------+----------------------+----------------+----------------------+------------------
    56 |          56 |                    0 |              0 |                   56 |               56

Every counter matches the aggregate block above, and none of them matches the
five rows the request returned.

3. The facet counts, counted independently
--------------------------------------------------------------------------------
SELECT p.name AS offering, count(*) AS applications
FROM applications a JOIN programs p ON p.id = a.program_offering_id
GROUP BY p.name ORDER BY p.name;

          offering         | applications
---------------------------+--------------
 Roster Primary 32426403   |           26
 Roster Primary 32448542   |           26
 Roster Secondary 32426403 |            2
 Roster Secondary 32448542 |            2

Identical to `facets.program_offering`, including the two-row offerings that
appear on no page of a 5-row window. A pick list harvested from the loaded rows
could not contain them, and could not carry a count at all.
