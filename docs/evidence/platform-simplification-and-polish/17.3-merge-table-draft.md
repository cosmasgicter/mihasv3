## Rule used to find a merge candidate

Two capabilities are a candidate only when both hold:

1. they are always granted together (same grant signature: the same role, the same
   default bundle or the same `permissions` value), and
2. no backend enforcement site and no frontend gate names exactly one of them.

If a gate names only one of them, merging would either widen that gate or narrow
the other, which changes who can do what.
